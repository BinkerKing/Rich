# Rich 视觉设计标准

## 目标

Rich 是长期使用的工作台，而不是展示页。界面应简约、大气、结构清晰，让用户优先阅读内容和识别操作。

## 基础视觉

- 默认采用近黑或炭灰纯色底；禁止为装饰加入渐变、光晕、网格纹理或大面积彩色底。
- 通过相邻灰阶区分页面、面板、卡片和悬停状态；以 1px 低对比细线建立边界。
- 主文字使用足够亮的近白；正文使用可读的浅灰；辅助信息使用中灰。不得以过暗文字换取“高级感”。
- 圆角保持小且统一（通常 5–8px）；不依赖大阴影制造层级。

## 色彩

- 单个页面应以黑、灰、白为主，色彩只表达状态或少量关键定位。
- 成功、警告、错误和链接可使用语义色；同一页面避免出现多个无语义的强调色。
- 新页面应继承已有页面的中性色阶，不自行引入新的主色。

## 图标与操作

- 优先使用清晰的线条图标，笔触和尺寸在同一工具栏中一致。
- 高频、已被用户理解的操作优先使用带 `title` 和 `aria-label` 的图标按钮；文字按钮只保留给首次理解困难或高风险操作。
- 不用彩色填充按钮作为常规入口。主操作应少而明确，非必要的“新建”入口不要占据页面头部。

## 信息与排版

- 先展示页面名称、当前内容和核心操作，再展示次要信息。
- 标题、正文、说明和元数据至少使用三个清晰的明度/字号层级；文本行高应支持长时间阅读。
- 卡片只在需要分组或可点击时使用；不可为填满页面而堆叠卡片。
- 空状态应说明内容来源或下一步，不用装饰性插图填充空白。

## 验收清单

- 页面截图中不应出现无语义的渐变、发光或彩色大底。
- 在常用窗口尺寸下，主标题、正文和次要文字均可快速辨识。
- 图标按钮可通过 `title` 和 `aria-label` 理解与访问。
- 新增颜色、边框、圆角和阴影均能说明其信息或交互目的。

# 字段设计移除外部 SQL 列

## 目标

移除项目管理数据字典“字段设计”表格中的“外部SQL”列，消除只有表头、没有字段行内容的冗余栏位。

## 范围

- 仅调整 `DictionaryFieldGrid` 的列定义。
- 不删除 `externalSql` 数据，也不改变表说明页或 Mapping 页的外部 SQL 查看能力。

## 验收

- 字段设计表头不再显示“外部SQL”。
- 字段设计表头的列数与每条字段行的单元格数一致。
- 其余字段设计列和其他视图不变。

## 验证

为字段设计组件增加回归测试，断言列配置不包含“外部SQL”，再运行该测试和 Web 端类型检查。

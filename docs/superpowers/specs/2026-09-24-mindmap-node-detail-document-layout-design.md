# 思维导图节点详情文档页布局设计

## 目标

保留思维导图右侧的节点详情抽屉，但将其内部从可折叠分区改为与文档工作台一致的阅读页：主文内容在左、固定目录在右。

## 范围

- 节点标题继续显示在抽屉标题栏；全屏、拖拽调宽与关闭行为保持不变。
- 抽屉正文改为单个可滚动的文档阅读区域，依次展示“说明、流程图、表格数据、外部文件”四个完整章节。
- 章节目录使用工作台文档的目录视觉和定位行为；点击目录平滑滚动至对应章节，并随滚动更新当前章节。
- “说明”继续支持编辑；流程图、表格和外部文件继续使用既有绑定与编辑能力。
- 窄抽屉不强行挤压正文：目录在非全屏状态隐藏，使用现有章节导航入口；全屏时显示固定右侧目录。

## 实现方式

在 `DeepWorkbenchView` 内保留现有节点资源和保存链路，只替换 `NodeDetailSection` 的折叠容器。新增一个节点详情阅读布局组件，使用独立的 `deep-node-detail-document` 类名复用文档工作台的排版规则，避免将工作台的全局壳层样式带入抽屉。

每个章节使用稳定的 DOM id；抽屉滚动事件按文档工作台的标题位置更新目录高亮。原有 `NodeDetailTableOfContents` 继续作为目录数据源，但文案升级为“工作台目录”。

## 验证

- 单元测试断言抽屉包含阅读布局、四个可定位章节和目录。
- 窄宽度与全屏两种状态下，确认目录的显示策略。
- 运行前端专项测试和生产构建。

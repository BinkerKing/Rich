## 如何使用这份清单

1. 改任何 UI 时先翻这份清单，看用户原始截图怎么画的
2. 把现有原图保存到 `docs/screenshots/greatme/` 并按表头文件名命名
3. 后续新截图按 `home-{state}.png` / `goals-{state}.png` 命名追加
4. 设计实现进度更新「状态」栏

# 东方汇理一代至三代产品库迁移工作台

## 当前边界

- 源端：一代产品库；目标端：三代产品库。
- 范围：公安查控、法院查控两类业务表及其必需关联数据。
- 当前产物仅为本地迁移模板和验收口径；**禁止连接、导出、写入或清理任何生产库**。
- 模板不包含连接串、账号、密码或真实业务数据。

## 执行链路

1. 盘点并确认源、目标表及字段映射；冻结本次迁移范围。
2. 在隔离演练库完成全量装载、增量/补数、校验和回滚演练。
3. 审批停机窗口后，按同一 `RUN_ID` 在生产执行；每个批次留下行数、校验值与操作人证据。
4. 切换后只允许经审批的补数重跑；未通过校验不得关闭回滚窗口。

## 模板说明

- `sql/01_full_load.sql`：全量基线装载，使用迁移控制表防止同一 `RUN_ID` 重复提交。
- `sql/02_incremental_repair.sql`：水位线增量和主键清单补数；重复运行必须覆盖同一目标主键而非重复插入。
- `sql/03_validation.sql`：数量、主键、关键业务字段和重复记录校验模板。
- `sql/04_rollback.sql`：仅删除本次 `RUN_ID` 写入的目标记录；不可删除非本次数据。

`{{...}}` 表示必须替换的对象名或字段名；`:...` 表示由受控执行器绑定的参数。数据库类型未确认前，这些是方言中立的审查模板，不能直接执行。

## 待确认问题清单

1. **字段映射**：公安查控、法院查控的源表/目标表全名；字段映射、类型转换、必填/default、枚举码转换及关联表依赖。
2. **主键策略**：目标主键沿用、重建还是映射表；自然键、外键装载顺序、序列/identity 回填，以及冲突时“覆盖/跳过/人工处置”规则。
3. **敏感字段与脱敏**：身份证件、姓名、手机号、案件/执行信息等字段清单；演练和验收数据的脱敏算法、可逆性、密钥保管位置及日志掩码规则。
4. **数据库类型**：源/目标数据库产品与版本、字符集、时区、大小写规则、事务隔离级别、SQL 方言和可用驱动；只提供凭据保管位置，不在本工作台记录凭据。
5. **停机窗口**：业务冻结开始/结束时间、只读或停服范围、允许的迁移时长、RPO/RTO、业务负责人、技术负责人和回滚决策人。
6. **增量依据**：可信的 `updated_at`/版本号/CDC 位点字段；删除标记语义；迟到数据最大时延；补数申请、审批和留痕规则。
7. **验收基线**：每张表预期总数、分机构/状态/日期汇总维度、不可变业务字段、抽样比例、差异容忍度和签字人。

## 演练与验收标准

- 至少一次全量演练和一次“全量后变更、删除、重复执行”的增量/补数演练。
- 同一 `RUN_ID` 重跑后：目标行数、业务主键集合和校验结果不变；不得新增重复记录。
- 两类表均通过：行数差异为零（或已签字的差异清单）、主键缺失为零、关键字段差异为零、目标重复记录为零。
- 回滚演练后：仅本次演练 `RUN_ID` 的记录被撤销，演练前既有目标数据不变。
- 验收证据包含：映射版本、运行参数、日志摘要、校验 SQL 结果、差异处置单、回滚演练结果和双方签字。

## 不可放行条件

字段映射、主键策略、脱敏规则、数据库方言或停机窗口任一项未确认时，不得生成生产连接配置或执行迁移。

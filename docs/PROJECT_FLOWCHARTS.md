# 项目流程图

入口：项目管理 → 项目流程图。

每个项目可以创建多个流程图任务，选择“代码分析”或“通用流程”模板。模板只有起始结构，不包含未经核验的业务逻辑。任务具有名称、分析目标，以及草稿、分析中、已完成三种状态。

## 操作

- 添加或拖动节点，拖动右侧连接点至另一节点左侧建立有向连线。
- 点击节点编辑名称、类型、源码位置、逻辑说明和源码核验标记。
- 点击连线填写分支条件；可删除连线。
- 双击节点或点击“进入子流程”展开下一层；通过面包屑返回。
- 搜索覆盖所有层级的节点名称、编号、源码位置和说明，点击结果跳转并聚焦。
- 点击“保存”写入项目数据库；刷新后重新打开任务可继续编辑。同一浏览器会话内保留未保存草稿，以便切换项目页面后恢复。
- 删除父节点会同时删除子流程节点及相关连线；删除整个任务前需要确认。

## 存储与实现

复用项目管理模块记录 API，模块键为 `flowcharts`，图数据保存在 `content.graph`：

- `version: 1`
- `objective`、`status`
- `nodes`：稳定 UUID、画布位置，以及 `label/kind/description/source/verified/scope`。
- `edges`：稳定 UUID、起点、终点及连线说明。

根流程的 `scope` 为 `root`；子流程的 `scope` 为所属父节点 UUID。子流程使用独立画布视图，不将父子层级解释为业务执行连线。后续增量维护时保留已有节点 ID，只修改相关节点和连线。

本功能复用 React Flow，没有增加图形依赖，也不需要新增数据库表。既有桌面应用需要重新构建前后端并启动新版本才能出现新入口。

# ACCCA 数据字典修复与验证

## 一代依据

`DataExtractMetroNewAccServiceImpl.extractAccountData` 使用 `RKAiftab` 当日快照，不是旧字典中的 `AifTab` 直接链路。代码依次：

- 排除 CNY/RMB、开户日等于销户日、`RKCiftab.cttp=B` 联行客户，以及 `closeAccount` 已记录的关户账户；
- 排除特定储蓄账户类型，仅保留 `SAS103/SAS104` 例外；
- 以非删除 Account 历史和已关户集合判断开户、关户与客户变更；
- 新户状态 11、关户状态 13、客户变更状态 12；关户沿用旧账户的性质、类别、限额、批件号；
- 机构必须通过一代 `branchConfig + branchMap` 解析，而非直接使用 `RKAiftab.brcd`；
- XML 输出的业务字段来自 `AccountServiceImpl`：动作、机构、账号、状态、主体、账户性质/类别、币种、业务日期、批件号、限额和备注。

## 二代修复

- 新增上游模型：`vtb.rkaiftab`、`vtb.rkciftab`、`vtb.close_account`、`vtb.acc_branch_map`。
- 报表目标：`vtb.t_safe_accca`。
- Mapping 场景：`SAFE1 Metro ACCCA 开关户与客户变更`，候选集 `accca_candidates`。
- 过程：`vtb.t_safe_accca_extract_test_data(p_datadate date)`。
- 报表重跑按账号、币种、数据日和有效标记去重；一代 XML 未写入的应用审计字段不凭空映射。

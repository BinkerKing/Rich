# AifTab 数据字典修复与验证

日期：2026-09-07  
范围：`AIF2.TXT -> vtb.aif_tab` 文件贴源层。

## 一代实际逻辑

- `DataImportServiceImpl.parseTxtFile` 以 UTF-16 读取 AIF 文件，使用 `split("\\|", -1)`，仅处理字段数大于 4 的行。
- `AifTab.isAccountIdFlag()`：仅当 `accountId.startsWith("40") && !accountId.startsWith("409")` 时保存。
- 每次导入先清空 `AifTab`，再批量装载；12 个业务字段按源文件第 0--11 位直接写入。

代码证据：

- `fbds_vtb/src/net/riking/business/service/impl/DataImportServiceImpl.java`
- `fbds_vtb/src/net/riking/business/model/AifTab.java:103-108`

## 本次 Mapping 修复

将默认场景由仅含 `full_extract` 的描述性口径改为可生成 SQL 的 `query_scope`：

```json
{
  "op": "query_scope",
  "from": "AIF2.TXT",
  "where": {
    "and": [
      {"source": "AIF2.TXT.account_id", "like": "40%"},
      {"not": {"source": "AIF2.TXT.account_id", "like": "409%"}}
    ]
  }
}
```

场景和表级元数据同时保留 UTF-16、`|` 分隔、保留尾空字段、字段数大于 4、先清空再装载的文件解析说明。

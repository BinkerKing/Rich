# ACCCB / Balance 数据字典修复与验证

## 一代证据

`BaseAccDataExtractServiceImpl.getImportACCBData` 逐条处理 `BalTab`：以账户号模糊匹配、币种、启用状态并按业务日/ID 倒序取得账户；同账户同交易日多条余额报错；已审核（`101002`）余额跳过；其他既有余额更新；没有账户只记录消息，不落库。每次执行前仅删除同交易日、动作 A、未审核（`101001`）的余额。

`BalTab` 的一代模型字段为 `accountNo`、`dealDate`、`credit`、`debit`、`balance`、`ccy`、`brcd`。二代新增的 `extract_date` 只是承接 `extract_ACCCB(extractDate)` 调用范围的批次控制字段，不是业务字段。

## 二代实现

- 暂存实体：`vtb.bal_tab` / 字典 `BalTab`。
- 业务实体：`vtb.safe_balance` / 字典 `Balance`。
- Mapping 候选集：`balance_candidates`，严格实现一代账户选择与已审核跳过条件。
- 生成过程：`vtb.safe_balance_extract_test_data(p_currentuserbranchcode text, p_datadate date)`。
- Rich 生成器补充表元 `extractionWriteSql`：仅在表声明需要“更新既有业务行”的情况下替换默认插入体；字段 Mapping 仍由界面 SQL 校验。这样可以保留一代更新时的审核/发送状态，而非删后重插改变状态。

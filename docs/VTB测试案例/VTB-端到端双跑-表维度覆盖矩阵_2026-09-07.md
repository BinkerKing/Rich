## 中间加工表独立案例

这些案例不以最终报表结果替代中间核验，而是分别比较一代与二代同名或同口径的加工节点：

| 案例 | 中间加工表 / 集合 |
|---|---|
| VTB-INT-01 ～ 03 | CifTab、AifTab、BlnTab |
| VTB-INT-04 ～ 06 | Customer、Account（safe_account）、Balance（safe_balance） |
| VTB-INT-07 ～ 09 | TransactionTab、BopTab、BopTransaction |
| VTB-INT-10 ～ 13 | CFACATab、CFACBTab、CFADATab、CFADBTab |
| VTB-INT-14 ～ 16 | FAEBaseInfo、FAEManage、FalWarehouse（fal_warehouse） |
| VTB-INT-17 ～ 18 | tmp_sac_jp_source、tmp_sac_jr_source |

每个最终报表案例配置七个步骤：冻结输入、一代中间链路逐节点快照、二代中间链路逐节点快照、中间节点差集、一代最终报表快照、二代最终报表快照、最终表差集及重跑核验。每个中间加工表案例配置五个步骤：冻结输入、两端表快照、逐字段差集、连续重跑核验。当前均为草稿，待一代可执行会话恢复后才可实际执行和判定通过/失败。

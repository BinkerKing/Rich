# JSHF/JSHG 数据字典修复与验证

## 一代依据

`FaeManageServiceImpl.exportJSHF/exportJSHG` 与 `FAEManage` 模型。

- JSHF 从 `FAEManage + FAEBaseInfo(jghFlag=1) + TxCode + UseType` 输出；字段包括基础申报号、交易码、用途、详细用途、批件号、填报人、电话和申报日期。
- JSHG 从 `FAEManage + FAEBaseInfo(jghFlag=2) + TxCode` 输出；没有用途字段。
- 导出门槛为管理信息已审核、未申报及当前机构；基础信息未审核时一代给出“先导出基础信息”提示。
- 一代 `FaeBaseInfoServiceImpl` 自动创建 FAEManage 的条件仅为结汇 `jghFlag=1` 且用途码可匹配。购汇管理信息没有从交易流水自动创建的代码路径，只能使用已有管理信息。

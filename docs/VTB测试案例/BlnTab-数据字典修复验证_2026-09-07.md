# BlnTab 数据字典修复与验证

一代依据为 `DataImportServiceImpl.parseTxtFile`、`BlnTab.java` 与 `BlnTab.hbm.xml`：读取 `BLN2.TXT` 的有效行（长度大于 4），使用 `split("|", -1)`；币种 `RUR` 改写为 `RUB`，业务日取第三列按 `-` 分割的第一段；`ldbl`、`cdbl` 均为 `DECIMAL(22,4)`，四个折算余额写 NULL。

修复了主键 Mapping：原字典随机生成 ID，与一代 Hibernate `native` 主键生成不一致，现改为数据库生成。其余字段口径已逐项复核。

验证：Mapping SQL 通过；`vtb.bln_tab` 实体结构一致；成功创建 `vtb.bln_tab_extract_test_data()`。在可回滚事务中插入 RUR、高精度余额样例，过程输出币种 RUB、业务日 `20260930`、`ldbl=123456789012345678.1234`、`cdbl=987654321098765432.5678`，且四个折算余额均为 NULL；事务已回滚。

保留差异：一代仅删除文件首个有效业务日的 BlnTab 数据；通用过程当前固定全表 DELETE，重跑生命周期仍需由生成能力支持。

# CFACATab 数据字典修复与验证

一代依据为 CFA VTB 提取逻辑：仅客户非 829240、用途含 `LD` 且以 `LOAN ISSUE` 开头、币种非 CNY 的交易进入国内外汇贷款签约前置。合同号从首个 LD 截取 13 位，金额取绝对值，导入日取运行日期。

修复：原 Mapping 将 `TransactionTab.transactionDate` 以通用 CAST 转 date，`YYYYMMDD` 输入在 PostgreSQL 生成过程中不能直接转换。已改用显式 `date_parse(from=yyyyMMdd)`，与一代日期解析一致。

验证：SQL、实体结构和 `vtb.cfaca_tab_extract_test_data(currentUserBranchCode, dataDate)` 创建通过。回滚事务以 USD、负金额、`LOAN ISSUE LD12345678901` 样例调用，输出债权人 310000167001、债务人/名称、起息日与导入日 2026-09-30、金额 12345.67、合同号 LD12345678901，全部符合一代。事务已回滚。

保留差异：少于 13 位 LD 后缀时一代抛 substring 异常，而 SQL 返回短串；空批次时一代保留原导入日数据，而通用过程全表 DELETE。均为待引擎能力闭环项。

# ACCCB 数据字典修复与验证

## 一代依据

`DataExtractMetroNewAccServiceImpl.extractBalanceData` 的实际来源是 `RKAiftab + RKTrntab`，不是旧字典中的 `BlnTab + TransactionTab` 直连链路。规则包括：

- 当日 `pstd` 与当日 `data_date`，排除 `definitiontwo=RVL`、空余额及空交易金额；
- 账号前三位（NRA 则取后续三位）必须等于交易机构；
- 对贷方交易按交易号、账号、币种、金额、对手账号、业务编号/起息日的层级键去重；
- `C` 汇总为贷方发生额、`D` 汇总为借方发生额，`RKAiftab.ldbl` 为余额；
- 已关户账户在余额和借贷发生额均为零时跳过；
- 关联最新 ACCCA 取得账户性质及主体信息，机构经 `branchConfig + branchMap` 取得。

XML 的一代实际输出字段为动作、机构、账号、发生日期、币种、贷方、借方、余额与备注；没有输出的二代应用字段不伪造来源。

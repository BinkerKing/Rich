# CFACBTab 数据字典修复与验证

一代逻辑包含提款、还本、付息三场景，均以 LD 合同号关联；还本和付息读取历史 CFA CB 余额，付息不扣减本金。当前 Mapping 已保留三场景、历史日期筛选及状态条件。

修复：三场景的 `ChangeDate` 原以普通 CAST 处理 `TransactionTab.transactionDate`，在 PostgreSQL 下不能处理 `YYYYMMDD`。已统一改为 `date_parse(from=yyyyMMdd)`。

验证：多场景 SQL、实体结构及 `vtb.cfacb_tab_extract_test_data(dataDate)` 创建均通过。回滚事务以 USD 5,000.55 的 `LOAN ISSUE LD22345678901` 调用，输出合同号、业务号、变动日/导入日 2026-09-30、提款币种 USD、提款金额和期末余额 5,000.55，符合一代提款口径。事务已回滚。

保留差异：LD 后不足 13 位的一代 substring 异常、空批次保留历史以及同日期历史无稳定二级排序，当前引擎无法完全表达。

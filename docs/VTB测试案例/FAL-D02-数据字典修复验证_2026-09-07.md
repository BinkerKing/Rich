# FAL D02 数据字典修复与验证

日期：2026-09-07  
范围：`T_SAFE_FALD_02`（贷款资产）

## 一代依据

`DataExtractVtbFalServiceImpl.extractD02()` 仅处理提取日 `FalWarehouse` 的 `falNo=D02` 记录。每条以 `refNo` 生成 D02：

- 取仓表委托贷款、对方、期限、币种和余额字段；只有 `isEntrustLoan=1` 时才填 D0202；
- 用 RefNo 在上期非汇总、未删除 D02 中取 D0210/D0212，作为本期 D0208/D0209；同时继承 D0201TYPE、D0221-D0223；
- D0213 固定 0，D0214 = D0210 + D0212 - D0208 - D0209，`ISSUM=N`；
- 新建状态、当前分支、Z01 ObjCode 与当前审计用户由运行上下文赋值。

## Mapping 修复

新增临时源 `tmp_fal_d02_source`，从 `vtb.fal_warehouse`（提取日、`fal_no='D02'`）连接上期 D02 快照。字段 Mapping 改为显式引用该源，修复了此前不可验证的 `FalWarehouse.*` 伪引用，并补齐：上期继承、D0202 条件、`ISSUM=0`、`BUSDATE`、`INVALID=0` 与运行时审计/分支/ObjCode。

字典 D0201TYPE、D0221、D0223 的类型同步为实际实体 `numeric(10,0)`。

## 生命周期差异

一代在提取前以本期表数据及申报/审核状态控制是否允许重提，且只删除本期。当前通用生成过程仍固定全表 `DELETE`，该过程级控制不能由 Mapping 配置表达。

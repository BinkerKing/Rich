# BOP C 数据字典修复与验证

依据 SAFE1 `BopcMetroExtractServiceImpl`。来源为 `BopTab(dataType='BOPC')`；按 `dealNo` 新增或更新未审核记录，`dataStatus=101002` 的已审核记录跳过。

除常规客户、金额、账户与汇率字段外，BOPC 专有映射为：`ACTUCCY/ACTUAMT` 取实际交易币种/金额，`LCBGNO` 取信用证号，`ISSDATE` 取期限起始日，`TENOR` 取期限天数。源码将 `inChargeAmount` 非空时映射为 `OUTCHARGECCY=TXCCY`、`OUTCHARGEAMT=inChargeAmount`；为空时显式清空两字段。

验证：65字段 Mapping SQL 通过。任务 `451794fe-2ccb-4843-89b3-ab6cca9a9813` 生成“有扣费”和“无扣费”两笔：前者输出 USD/12，后者两字段为空；实际币种/金额、信用证号、开证日、期限均正确。任务 `711ec300-a8c8-4880-b04b-d9903705f709` 验证未审核记录实际金额由 850 更新为 860；任务 `9efece42-fcbd-483c-a8b7-5e57e4f03b76` 验证审核后源值改为 870 但目标保持 860。

# 项目说明设计

项目管理顶部新增“项目说明”菜单，作为项目的人类说明页和 AI 上下文入口。页面采用单个大富文本编辑区，不规定章节结构；用户可自由组织项目背景、架构、运行方式、约束和当前状态。

项目说明复用 `pm_module_items`，模块键为 `description`，每个项目只取该模块的首条顶层记录作为当前说明。记录标题固定为“项目说明”，正文保存在 `content.html`。保存继续经过现有模块条目仓储，因此 PostgreSQL、SQLite、更新时间和搜索索引保持一致，不新增数据库表。

前端首次进入时读取说明。无内容时展示写作提示；点击编辑后使用现有 `ProjectRichTextEditor`，保存与取消显式控制，不自动覆盖数据库。页面展示最后更新时间和保存状态，并适配项目工作区高度、内部滚动。

HTTP 提供项目说明专用 GET/PUT 接口，隐藏单例条目的实现细节。MCP 增加只读 `project_management_get_description` 工具，AI 接入项目后可以直接读取完整 HTML 以及剥离标签后的纯文本。项目说明也进入现有全局搜索结果。

第一版不提供历史版本、多人协作、模板字段或 AI 自动生成，保持单一、可靠、易维护。
